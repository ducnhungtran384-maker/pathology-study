网站：https://ducnhungtran384-maker.github.io/pathology-study/

在电脑点击“云同步 → 首次使用”，保存同步码；手机打开同一网址，输入同一码。同步码相当于密码，不要公开。

旧网址或离线版的学习进度：先“更多 → 导出进度”，再在本网站“更多 → 导入进度”。

部署使用 GitHub Pages 与 Supabase Free。免费云数据库长时间不活跃可能暂停；本地进度与导出备份继续可用。

仓库只有网页和题库图片，不包含个人学习进度或服务器秘密密钥。
